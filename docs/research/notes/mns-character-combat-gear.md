## 1. Leveling: max level, XP curve, points per level, level gating, death penalty

### Takeaway
Max level is 100. XP to the next level is a power curve, (10 x (1 + 0.2 x L))^2.4, from 389 XP at level 1 to ~366k at level 99, while a same-level common mob's base XP only rises from ~55 to ~178, so equal-level kills per level climb from ~7 to ~2,055 and levels 50-100 hold 89 % of all XP. Each level gives 1 stat, 1 talent, 1 spell and 0.5 passive point in CTE2; ascendancy points come only from quest milestones. Gating is by level everywhere (gear, spells by row, support/aura gems, support-gem slots, dimension level bands), with a 3-level leeway before XP/loot penalties.

### Cited Findings
- MAX_LEVEL = 100 — `CTE2 1.1.3 instance: config/openloader/data/cte_mns/data/mmorpg/mmorpg_game_balance/`
- XP formula: `getExpRequiredForLevel(L) = (10 * NORMAL_STAT_SCALING.getMultiFor(L))^2.4`; `getMultiFor(L) = base + per_level * (L-1)` (NORMAL: base 1.0, per_level 0.2, uncapped); XP to level up from L uses L+1; base mob XP = `50 + (4 * multi(L))^1.1` — `Mine and Slash source (1.20-Forge): src/main/java/com/robertx22/mine_and_slash/uncommon/utilityclasses/LevelUtils.java`, `Mine and Slash source (1.20-Forge): src/main/java/com/robertx22/mine_and_slash/database/data/game_balance_config/LevelScalingConfig.java`, `Mine and Slash source (1.20-Forge): src/main/java/com/robertx22/mine_and_slash/capability/entity/EntityData.java`
- Computed table (XP to next level / base XP of a same-level common mob / kills needed): L1 389 / 54.6 / 7; L10 3,508 / 64.3 / 55; L20 11,954 / 75.8 / 158; L30 26,806 / 87.8 / 305; L40 48,998 / 100.3 / 489; L50 79,313 / 113 / 702; L60 118,431 / 125.9 / 941; L70 166,963 / 139 / 1,201; L80 225,464 / 152.4 / 1,480; L90 294,448 / 165.8 / 1,776; L99 365,891 / 178.1 / 2,055. Cumulative XP: to reach 10 = 13,265; 20 = 81,513; 30 = 262,191; 50 = 1.24M; 100 = 11.38M (levels 1-50 = 10.9 % of the total) — computed from the formula above.
- Actual XP per kill = base x mob vanilla-health multiplier x mob rarity exp_multi (1.0 common to 15.5 uber) x entity datapack exp_multi x server exp_gain_multi (1.0 in CTE2) x dimension exp_multi x player Bonus EXP stat x favor x map multiplier; then party bonus (+100 % per extra member up to 4, split evenly) and the level-distance penalty — `Mine and Slash source (1.20-Forge): src/main/java/com/robertx22/mine_and_slash/event_hooks/my_events/OnMobDeathDrops.java`, `CTE2 1.1.3 instance: defaultconfigs/mine_and_slash-server.toml`

MnS defaults are more generous: STATS 2/level, PASSIVES 1/level, ASCENDANCY 0.1/level (max 9), TALENTS bonus 30 — `CTE2 jar: Mine_and_Slash-1.20.1-6.3.14/data/mmorpg/mmorpg_game_balance/original_balance.json`
- Free points = base + floor(level x per_level) + bonus (capped at max_bonus_points), capped at max_total_points — `Mine and Slash source (1.20-Forge): src/main/java/com/robertx22/mine_and_slash/database/data/game_balance_config/PlayerPointsType.java`
- CTE2 grants bonus/ascendancy points through quests, e.g. "Completing Defenders of the Nether now grants you 3 Ascendancy points instead of 1. - Rested XP: professions generate rested combat XP and vice versa (COMBAT_TO_PROFESSION 0.25, PROFESSION_TO_COMBAT 0.05) — `Mine and Slash source (1.20-Forge): docs/mechanics/rested_exp.mdx`, `CTE2 1.1.3 instance: defaultconfigs/mine_and_slash-server.toml`
- CTE2 has tuned kill XP repeatedly ("Kill EXP has been doubled", "Reduced kill experience by 25%", "Increased kill experience gain by 33%") and added quests "to help a bit with the experience gain from level 45-55" — `CTE2 GitHub repo: ARCHIVED%20CHANGELOG.MD`
- Up to 3 characters per player in 1.1.3 (MAX_CHARACTERS = 3); CTE2 2.1.0 raised it to 7 — `CTE2 1.1.3 instance: defaultconfigs/mine_and_slash-server.toml`, `CTE2 GitHub repo: CHANGELOG.md`

### Inferences
- The curve is the main grind engine: level 99 needs ~294x the kills of level 1 at equal level. CTE2 compensates with quests, rested XP and party bonuses, and reviewers still flag pacing jumps ("why is the epilogue 30 levels further then the previous chapter?" — [moddex review 4142](https://moddex.gg/modpack/craft-to-exile-2/reviews/4142)).
- At max level a CTE2 character has ~100+25 talent, 100+50 stat, 100+10 spell, 50+10 passive and up to 10 ascendancy points: five separate point currencies, each with its own screen and its own minor/major reset potion.
- Every spell is unlocked by level 30 (row 7); levels 30-100 add only ranks, support-gem slots (up to 40) and gear, so the second half of leveling has few qualitative unlocks.

### Gaps
- The exact vanilla-health XP multiplier (`LootUtils.getMobHealthBasedLootMulti`) was not traced, so real kills per level for big mobs are unknown; the kills above are for a base-multiplier common mob.
- CTE2 quest XP volume (FTB Quests) is outside this scope; real leveling time per level is unmeasured.

## 2. Stats: attributes, categories, tenacity-like stats, counts, display

### Takeaway
Three core attributes (STR, DEX, INT), each feeding 5-6 derived stats; underneath sit five resources (health, magic shield, mana, energy, blood) and a very large stat model: 743 named stats in the lang file and 654 distinct stat IDs referenced by CTE2's data, of which 88 appear on normal prefixes/suffixes. There is no stat literally called tenacity: incoming effects are reduced through per-ailment resistances (100 % = immunity), "effectiveness of Negative buffs on you", specific immunities and boss-only CC resistance; there is no generic reduced-duration-of-effects-on-you stat.

### Cited Findings
- Attributes per point (CTE2): STR = +2.5 flat health, +0.2 health regen, +0.25 % armor, +0.1 % total damage, +0.25 % crit damage, +1 % summon health; DEX = +0.2 % projectile damage, +0.25 % attack speed, +1 % increased crit chance, +1 % increased energy regen, +0.25 % increased dodge; INT = +0.2 % spell ("int") damage, +0.3 % healing, +0.2 % summon damage, +1 % mana regen, +0.25 % magic shield — `CTE2 1.1.3 instance: config/openloader/data/cte_mns/data/mmorpg/mmorpg_stat/strength.json`
- One allocated stat point = 1 attribute point (level-scaled at level 1, i.e. not scaled) — `Mine and Slash source (1.20-Forge): src/main/java/com/robertx22/mine_and_slash/saveclasses/ExactStatData.java`; attributes from other sources scale with CORE_STAT_SCALING 1 + 0.05 per level (capped at 100, so x5.95 at max) — `CTE2 1.1.3 instance: config/openloader/data/cte_mns/data/mmorpg/mmorpg_game_balance/`, `Mine and Slash source (1.20-Forge): src/main/java/com/robertx22/mine_and_slash/database/data/stats/StatScaling.java`
- Gear attribute requirements scale: e.g. axe `scaling_req {strength: 0.4}`, plate `{strength: 0.4}`, brigandine `{strength 0.25, dexterity 0.25}`; STAT_REQ_SCALING base 2 + 2 per level — `CTE2 1.1.3 instance: config/openloader/data/cte_mns/data/mmorpg/mmorpg_base_gear_types/`, `CTE2 1.1.3 instance: config/openloader/data/cte_mns/data/mmorpg/mmorpg_game_balance/`
- Resources: health, magic_shield, mana, energy, blood (blood replaces mana for the Blood Mage keystone) — `Mine and Slash source (1.20-Forge): src/main/java/com/robertx22/mine_and_slash/saveclasses/unit/ResourceType.java`; player base (scaled to level): 80 health, 50 mana, 50 energy, 2.5 health regen, 2.5 MS regen, 2 mana regen, 2 energy regen, 2+1 weapon damage, 4 % crit, +25 % crit damage, -25 % elemental and chaos resist, 5 % leech caps, 3 max summons — `CTE2 1.1.3 instance: config/openloader/data/cte_mns/data/mmorpg/mmorpg_base_stats/original_mode_player.json`

FINAL_DAMAGE, POST_FINAL_DAMAGE_CHECKS) — `CTE2 jar: Mine_and_Slash-1.20.1-6.3.14/assets/mmorpg/lang/en_us.json`

- Display: Main Hub on H with Stats, Talents, Classes, Hotbar, Ascendancies, Library (searchable list of uniques, runewords, spells), per-player Features/Configs (damage numbers in chat, cast-fail messages, XP chat messages) — `Mine and Slash source (1.20-Forge): docs/newbie_guide/leveling_up.mdx`, `Mine and Slash source (1.20-Forge): docs/misc/ingame_library.mdx`, `CTE2 1.1.3 instance: defaultconfigs/mine_and_slash-server.toml`, `Mine and Slash source (1.20-Forge): src/main/java/com/robertx22/mine_and_slash/mmorpg/registers/client/KeybindsRegister.java`; CTE2 client config: in-depth tooltips by default, RPG-style player HUD, floating damage, rarity item borders — `CTE2 1.1.3 instance: config/mine_and_slash-client.toml`; CTE2 2.1.0 added "hold ALT on some stats in tooltips to see more details" — `CTE2 GitHub repo: CHANGELOG.md`

### Inferences
- A typical build cares about roughly 20-30 stats: its damage type and element, the matching % / MORE / penetration stats, crit pair, attack or cast speed, one or two resources and their regen/leech, life or magic shield, armor or dodge, four resists, and a few utility stats (move speed, CDR, AoE). The other ~600 referenced stats are niche conditionals (per-weapon damage, per-charge, procs, X-per-Y conversions, ailment sub-stats) that mainly bloat tooltips. This is my estimate, not a measured number.
- The CTE2 dev's own 2.0 note lists "confusion from certain skills and stats" as a major pain point (`CTE2 GitHub repo: ARCHIVED%20CHANGELOG.MD`), consistent with stat bloat being a real cost.
- MnS has no incoming-duration reduction, so Realmforge's "tenacity" is a genuine gap-filler rather than a copy.

### Gaps
- I did not count how many of the 654 referenced stats a real endgame character actually has non-zero; no player data.
- Whether `inc_effect_of_negative_buff_on_you` also shortens duration (vs magnitude only) was not traced through the effect code.

## 3. Talent tree, classes (spell schools) and ascendancies

### Takeaway
One shared PoE-style talent tree of 1,321 placed nodes (950 small stat nodes, 311 "big" notables, 54 MAJOR keystones called Gamechangers, 6 start points) of which a max-level character can take ~126 (~10 %). Ten classes (spell schools) of 12-21 spells plus 8 class passives each, of which a character may invest in at most 2. Sixteen ascendancies with 7 nodes each (one ascendancy per character), funded by up to 10 quest-granted points. Respec is cheap: craftable potions.

### Cited Findings
- Talent tree grid: 139 rows x 173 columns; cells of 1 character are connectors, cells longer than 2 characters are nodes, `[CENTER]` sets the view; connections are path-found between nodes within 12 cells — `CTE2 1.1.3 instance: config/openloader/data/cte_mns/data/mmorpg/mmorpg_talent_tree/talents.json`, `Mine and Slash source (1.20-Forge): src/main/java/com/robertx22/mine_and_slash/database/data/talent_tree/parser/TalentGrid.java`, `CTE2 1.1.3 instance: config/openloader/data/cte_mns/data/mmorpg/mmorpg_talent_tree/modpacker_resources/guide_for_modpackers.txt`
- Node census (my count, perk types from jar+pack perks): 1,321 node cells = 950 STAT + 311 SPECIAL + 54 MAJOR + 6 START; 312 distinct perk definitions. ## 4. Spells: acquisition, ranks, hotbar/keybinds, costs and cooldowns, support gems, auras, redundancy, UI

### Takeaway
Spells are learned by spending spell points in one of max two class trees (ranks 1-16, +up to 8 bonus ranks from gear in CTE2), then placed on an 8-slot hotbar (default R, V, C, G and Shift+R/V/C/G), each slot taking up to 5 support gems. Spell damage is mostly a % of the MnS weapon's damage, so a weapon with MnS stats is mandatory even for mages. 235 spell definitions exist, 170 of them class spells, with heavy elemental-reskin redundancy; 28 aura gems reserve "spirit" (100 base). CTE2 2.1 later replaced per-spell cooldowns with a 1 s global "Recovery" and partially rolled it back after feedback.

### Inferences
- The 8-slot bar plus 4-key + Shift layout is the de facto ARPG-in-Minecraft standard, and it is what makes 170 spells survivable: a build only ever uses ~6-8. The other ~160 are menu noise for that character.
- Depth comes from support-gem trade-offs (MORE/LESS pairs, one-of-a-kind groups), keystones and combo tags; bloat comes from same-shape elemental reskins and the separate aura-gem layer (28 gems + 9 slots + a spirit budget on top of buff spells).
- The 2.1 Recovery change and its partial rollback is direct evidence that one global cooldown for everything feels bad for buffs, toggles and movement.

### Gaps
- No usage statistics on which spells players actually pick; redundancy is judged from data shape and the changelog, not from telemetry.
- The cooldown/cast numbers are 1.1.3 values; 2.1.x numbers differ (Recovery system), and the post-2.1 datapack is not available locally.

## 5. Gear and loot: rarities, affixes, uniques, runewords, gems/runes/jewels, currency crafting, salvage

### Takeaway
Gear is Diablo/PoE-style: 6 normal rarities (weights 729/486/162/81/27/9, 1-6 affixes) plus Unique (220) and Runed (57 runewords), affix "tier" = affix rarity, which fixes the roll band (common 0-17 % ... mythic 86-100 %). Crafting is bounded by a per-item "potential" budget (75-200) that 42 currencies spend; several currencies gamble with a 25 % item-destroy chance. Loot volume is high (10 % gear chance per eligible kill) and players report gear upgrades as luck-driven; salvaging into rarity stones is the intended sink.

Noise: the 6 soul modifiers, 6 sharpening stones, 63 gems x 3 stat profiles, 22 runes x 2 profiles, 105 enchants, 31 watcher-eye lines and 8 omens.
- The potential budget is a good idea: it caps how far one base can be rerolled and makes each currency use a decision. The 25 % destroy outcomes make crafting a casino.
- Loot overload is structural: a 10 % gear roll on every kill plus 9 other drop tables means the salvage station and a loot filter are mandatory, and the filter arrived only in CTE2 2.1.

### Gaps
- The full salvage output table and the gear-crafting profession recipes (crafted gear has CRAFTED_GEAR_POTENTIAL_MULTI 1.0 in CTE2) were not enumerated; professions are outside scope.
- Actual rarity probabilities after level gating (epic needs level 10, legendary 25, mythic 50) and favor were not simulated.

## 6. Mobs: rarities, affixes, level scaling, bosses, overrides

### Takeaway
Mobs take the level of the nearest player (lowest party member) clamped to a per-dimension band, plus +/-1 variance; nine mob rarities (common 1024 ... mythic 1 by weight, plus boss, uber, summon) multiply HP, damage, XP and loot; 25 mob affixes add flavour (elemental conversion, vampiric, swift ...). CTE2 made level scaling much steeper than MnS defaults (linear +15 % HP per level and exponential HP and damage factors), producing several stacked multiplicative layers the dev himself has had to retune.

### Inferences
- Rough order of magnitude (my estimate, ignoring entity/dimension configs): a level-50 common zombie (20 vanilla HP) has ~20 x 8.5 x 10.8 x 1.38 = ~2,500 HP and a level-100 one ~12,000 HP; the player's base 80 HP scales only x20.8 (to ~1,660) before gear and talents, so gear and passive multipliers must keep pace. This is why "Not replacing your low level gear" is a listed newbie mistake.
- Scaling to the nearest player keeps every area relevant but removes the feeling of out-levelling a region; CTE2 restores structure through per-dimension clamps.
- Stacked multipliers (rarity x entity x dimension x exponential x map tier x level gap) are hard to reason about; the dev has repeatedly retuned them, a warning for any data-driven balance with many independent multipliers.

### Gaps
- Boss-specific mechanics (dungeon/map bosses, uber bosses) belong to the dungeon/maps researcher; only their rarity numbers are covered here.
- The HP/damage estimates were not checked against in-game numbers.

## Relevance to Realmforge

### Adopt
- **Data-driven registries for everything balance-related.** MnS keeps spells, perks, affixes, rarities, mob rarities, dimension level bands and per-mob overrides as JSON; CTE2 rebalanced the whole game through a datapack alone (e.g. 2x jar uniques, 6x runewords). Realmforge's datapack registries (spells, talents, affixes, dungeon/boss definitions) should include a per-realm config shaped like `mmorpg_dimension` (min/max level, strength multi, XP and loot multi) and per-mob overrides like `mmorpg_entity` (hp/dmg/xp/loot multi, forced rarity, min level), so realm bands such as 10-13 / 13-17 / 17-20 dungeons are pure data.
- **Level-distance penalty with leeway** (MnS/CTE2: no penalty within 3 levels, -33 % per extra level, floor 25 %; out-levelled mobs hit harder). It supports chapter caps and recommended realm levels (first realm open from 1, recommended from 5) without hard locks.
- **Cast-fail feedback and an always-available info layer**: explicit messages for wrong weapon / no resource / cooldown / banned area, a searchable in-game library of all spells and uniques, damage-breakdown chat on demand. Realmforge's spellbook UI and tooltips with live numbers (roadmap C3b) can include the same failure reasons.
- **Cheap, craftable respec** (MnS Minor = 10 points, Major = full reset; diamonds + a salvage stone). It suits the roadmap's respec command and the owner's dislike of punishing grind.
- **Keystones with explicit drawbacks** (Blood Mage, Summoner, True Hit, Harmony) and **MORE/LESS support modifiers**: these are where MnS's depth actually lives. Realmforge's spell ranks with threshold effects and its glyphs (M3) can use the same pattern: a rank or glyph that adds an effect and costs something (more cost, less damage, longer cooldown).
- **Mob rarity tiers with geometric weights** (1024/256/64/16/4/1, HP x1-3.5, damage x1-1.75, XP/loot x1-8.75) and a small affix list (Massive, Swift, Vampiric, elemental): cheap variety that helps realms feel alive. Keep the HP/damage multipliers modest so an elite is a fight, not a wall.
- **Default spell keys without modifiers**: the owner's R T F G C V X Y layout avoids MnS's Shift-combos for slots 5-8; keep it, and keep the bar visible when empty (MnS hides it when empty, which hides the system from new players).

### Adapt
- **XP curve**: MnS's (10 x (1 + 0.2L))^2.4 makes level 99 cost ~2,055 equal-level kills. For 10-level chapters, scale mob XP with level so kills (or minutes) per level stay roughly flat inside a chapter and grow slowly between chapters; check it with the roadmap's balance simulation (M3) against a "minutes per level" target rather than raw XP numbers.
- **Points per level**: MnS/CTE2 gives 1 stat + 1 talent + 1 spell + 0.5 passive (+ quest ascendancy). Realmforge's 1 skill point + ~2 stat points per level is already leaner; take MnS's idea of quest-granted bonus points (CTE2 gives talent and ascendancy points from quests) for chapter milestones.
- **Attributes**: MnS attributes each feed 5-6 small derived stats (STR: +2.5 HP, +0.2 regen, +0.25 % armor, +0.1 % damage, +0.25 % crit damage, +1 % summon HP). Realmforge's "10 STR = +10 % attack damage" milestones should stay at 1-2 effects per attribute so a stat point is legible. Note MnS lets gear attributes scale x5.95 with level, which dwarfs allocated points; avoid that if allocated points are meant to matter.
- **Spell ranks**: MnS interpolates a min-max range over 16 ranks (+8 from gear) with cost growing too; CTE2 2.1 added threshold effects ("at 4 stacks of Overheat") and support slots at ranks 4/8/12/16/20. Realmforge's ranks 1-8 can interpolate numbers and add a new effect at fixed ranks (e.g. 3, 5, 8); expose the next threshold in the spellbook tooltip.
- **Toggles and auras**: MnS uses a separate aura-gem layer: 28 gems, 9 slots, a 100-spirit budget, 25-40 spirit each. For Realmforge's toggle spells (auras, self-buffs, 2-3 state cycles), take the reservation idea (a toggle reserves a share of max mana or a small "focus" budget instead of paying per cast) but keep toggles as ordinary spells on the 8-slot bar, at most 2-3 active.
- **Global cooldown**: MnS ran a 3-tick GCD; CTE2 2.1 imposed a 1 s global "Recovery" on everything and within two days exempted buffs, curses, utility and movement (0.25 s minimum cast). For roadmap C3a: a GCD around 1 s for damaging spells and off-GCD (or a very short GCD) for toggles, buffs and movement from the start.
- **Tenacity**: MnS only has per-ailment resistance (100 % = immunity), "effectiveness of negative effects on you" and targeted immunities; bosses use a CC-resist spell and mob rarities cap chill slow (25-100 %). Define Realmforge tenacity as shorter incoming negative effects, with a cap (e.g. 50-60 %) and diminishing returns, and give bosses their own CC-resistance mechanic, so tenacity never removes boss mechanics outright.
- **Affix tiers = roll bands tied to rarity**: MnS's common 0-17 % ... mythic 86-100 % bands are a simple, visible quality indicator for M2's five tiers (e.g. five 20 % bands); pair with item level as MnS does.
- **Bounded crafting ("potential")**: every item has a budget (75-200) and each currency use spends 0-25 of it. Use a reforging-station budget (number of rerolls or a material cost that rises per reroll) so targeted crafting replaces RNG farming, without the 25 % destroy outcomes.
- **Mob level source**: CTE2 scales mobs to the nearest player and clamps to dimension bands. Realmforge realms and dungeons should use fixed bands per area (10-13, 13-17, 17-20) so the chapter structure is felt; scaling to the player only inside the band, if at all.

### Avoid
- **Stat bloat**: 743 named stats, 654 referenced by CTE2 data, 88 distinct stats on prefixes/suffixes alone; the dev himself cites "confusion from certain skills and stats". Aim for a player-facing set of roughly 30-40 stats (owner: "big ... complex, but not complicated").
- **Spell bloat**: 170 class spells (12-21 per class) with elemental reskins (3 novas, 4 traps, 7 totems in one class, 3 golems, 3 elemental finishers, 8 crusader aura spells next to 28 aura gems), all unlocked by level 30 while a build uses 6-8. This is the owner's complaint about CTE ("unnecessary spells") and Iron's Spells ("over-spelled"); with chapter N allowing 4N spells, give each class few spells with distinct roles.
- **Talent filler**: 950 of 1,321 tree nodes are +1 attribute / +x % filler (70 copies of +1 INT). Prefer WoW-style per-class trees with fewer, impactful nodes, matching the vision's warning about a tree made of "+1 attack damage".
- **Loot volume and luck**: a 10 % gear roll per kill, 6 rarities + uniques + runed, 220 uniques with 4-7 random-range stats, a salvage loop, and a loot filter that arrived only after years ("long-requested"); players call it "1000 gear for single useful piece". The owner hates RNG grind; prefer the roadmap's choice rewards, targeted crafting and lower drop volume with higher relevance.
- **Gambling with item destruction** (Orb of Chaos 25 % destroy, jewel corruption, harvest essences 15 % destroy) and a 42-currency zoo; keep a few crafting materials with deterministic or bounded outcomes.
- **Weapon-gated spells**: MnS spells need an MnS weapon ("Weapon has no Mine and Slash Stats/Soul" fails the cast) and most spell damage is a % of weapon damage, so mages chase weapon damage like warriors. If Realmforge spells scale from gear, use a spell-power stat for casters rather than weapon damage.
- **Stacked opaque multipliers on mobs** (linear + exponential level factors x rarity x entity x dimension x map tier x level gap): the CTE2 dev has had to rework them for "gotcha" moments and cut damage by 12-25 % again in 2.1. Keep mob power a short, testable formula (level curve x rarity x optional per-boss override).
- **Back-loaded leveling to 100**: 89 % of all XP lies in levels 50-100 and all spells are unlocked by 30, so the second half is mostly numeric. With 10-level chapters, every chapter should unlock something qualitative (new spell slots per the 4N rule, rank thresholds, a realm), which the owner's design already implies.
