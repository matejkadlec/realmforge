# 0002. Hybrid: own core mod plus a modpack

Date: 2026-10-11

Status: Accepted

## Context

The owner wants the core of the game (quests, dimensions, dungeons, mobs, bosses, skills, spells, talents, glyphs, professions) to be 100% our own, with tightly interconnected systems. Third-party mods should only cover QoL that does not change the game itself, with a few exceptions. Options compared in [research notes, section 1](../research-notes.md#1-form): a giant all-in-one mod (Advent of Ascension style), a curated modpack, or a hybrid.

- A pure modpack would source exactly the content the owner wants to own from other mods (Otherworld: about 400 mods, no single source of truth).
- A pure giant mod would force us to write our own map, JEI and storage, and Advent of Ascension shows how a single huge mod stalls on version changes.

## Decision

- **Hybrid.** Our own core mod holds all RPG systems; the modpack adds third-party QoL, UI, performance and library mods (plus Better Combat, MineColonies, Distant Horizons and Iris unchanged, see [0004](0004-build-rpg-systems-in-house.md); MineColonies is paused on Minecraft 26.1.2 until it has a build there, [0026](0026-platform-minecraft-26-1-2-neoforge.md)). The game ships as a modpack, the core mod also as a separate jar.
- **One core mod**, mod ID `realmforge`, Java package `io.github.matejkadlec.realmforge`, organised in feature packages (classes, spells, talents, loot, dungeons, ...). Split into more jars only when there is a concrete need.
- **Dev-only QA mod**, mod ID `realmforge_qa` in `qa-mod/`: depends on the core mod, holds debug commands, test scenarios and GameTests, and is never released.
- **Modpack** defined in the repo with packwiz (`pack/`), metadata only; composition is decided in [0013](0013-modpack-composition.md) (modpack composition).
- **Integrations with QoL mods are written by us** inside our mod or pipeline: Jade and JEI plugins, Xaero minimap icons for our mobs as JSON (no code), configs for third-party mods generated by the pipeline.

## Consequences

- Full control over gameplay; ready-made QoL; medium time to a playable version.
- Medium compatibility risk, limited to QoL, performance mods and the four big unchanged mods; covered by the whole-pack boot test ([0010](0010-testing-strategy.md)).
- Two distributables to maintain: the mod jar and the modpack ([0008](0008-distribution-github-and-curseforge.md)).
- Missing small UI mods on NeoForge 1.21.1 become our own work (see [0013](0013-modpack-composition.md)).
