# 0008. Distribution: GitHub Releases now, CurseForge later

Date: 2026-10-11

Status: Accepted

## Context

The project is open source on GitHub. Constraints from [research notes, section 3](../research-notes.md#risks) and [section 7](../research-notes.md#7-repository-and-workflow):

- Since 2026-08-13 Modrinth does not publicly allow projects "primarily generated by AI"; Realmforge is vibe-coded with AI-generated assets.
- Key dependencies are CurseForge-only (MineColonies with Structurize, BlockUI and Domum Ornamentum, paused on Minecraft 26.1.2 by [0026](0026-platform-minecraft-26-1-2-neoforge.md); FTB Quests with FTB Library and FTB Teams, still CurseForge-only on 26.1.2), and a Modrinth pack (`.mrpack`) may only download from Modrinth, GitHub and GitLab.
- Xaero's mods are monetised only via CurseForge and Modrinth; outside them (e.g. a GitHub Release) we link to his page.

The research report proposed GitHub and CurseForge together; the owner chose to start with GitHub only.

## Decision

- **GitHub Releases now; CurseForge later.**
- **Modrinth is not a publishing target.** Mods may still be sourced from Modrinth for the pack.
- **Version format:** `0.1.0+mc1.21.1` (SemVer with the Minecraft version as build metadata).
- **Releases are built from tags `v*`** by GitHub Actions: the `realmforge` jar plus the modpack. The QA mod is never released.
- CurseForge publishing, when added, uses mc-publish or mod-publish-plugin from the same tag workflow.

## Consequences

- No third-party jars are ever attached or committed; the modpack is packwiz metadata only.
- When CurseForge publishing is added, the pack's mod sources and the CurseForge modpack rules have to be checked first.
- Releases target the licenses in [0009](0009-licensing.md): the jar is open (MPL-2.0 / CC BY 4.0), the modpack is All Rights Reserved.
